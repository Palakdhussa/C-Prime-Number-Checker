# C Prime Number Checker

A simple C program that checks whether a given number is a prime number or not.

## Features

* Takes a number as input from the user
* Checks whether the number is prime
* Uses a `for` loop to check divisibility
* Displays the result clearly

## Technologies Used

* C Programming Language

## How to Run

1. Download or clone this repository.
2. Open `prime_checker.c` in a C compiler.
3. Compile the program.
4. Run the program.
5. Enter a number when prompted.

## Example

```text
Enter a number: 7
7 is a Prime Number.
```
